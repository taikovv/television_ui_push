# Security

This project includes a developer-mode TV app and optional firmware-specific research tools. The native Home helper uses an unsupported SDK command-execution workaround; it is not part of ordinary app installation. Review its code and recovery requirements before use.

For a vulnerability or exposed credential, use [GitHub's private vulnerability reporting](https://github.com/taikovv/television_ui_push/security/advisories/new). Do not post exploit-sensitive reports or secrets in public issues. Include the affected commit, model/firmware where relevant, and a minimal redacted description. There is no guaranteed response time or formal long-term support policy.

Do not attach certificates, passwords, DUIDs, account tokens, local addresses, recovery archives, or raw probe logs. If a signing key or token is exposed, remove access and rotate the affected credential; deleting a public file alone does not revoke it.
