tv-home native Home routing — recovery

Applies only to UN55CU7000FXZA / the expected DUID in private .local/tv.json,
firmware T-KSU2ECAKUC-0080-2024.2, Tizen 8.0 ARMv7.
Target: WGuqy2ffiw.Home. Runs only as SDK UID 901, never root.

From the tv-home project directory:
  python3 tools/native-home/run.py query
  python3 tools/native-home/run.py restore

Restore before uninstalling the launcher or changing its app identity.
The runner re-stages its compiled files and original.json for every run;
it does not depend on the previous TV temporary files remaining intact.
The .local/native-home/original.json baseline must never be overwritten.

Restore verifies all five settings and the native Home operation against
the original snapshot. Firmware guards apply to restore too: review before
updating the TV firmware. Keep Developer Mode enabled for recovery.

If you created a private recovery archive, extract it and change into its
project directory before running the restore command above. The public
repository does not contain your recovery snapshot or an archive.
It uses ~/tizen-studio/tools/sdb and .local/tv.json; update the IP if DHCP
changes it. It does not need the Microsoft SDK or signing passwords.

This is an unsupported non-root method. See docs/HOME_ROUTING.md for setup
and recovery requirements before applying it to a supported TV.
It uses the reviewed SDK package-name command-execution workaround with
one-shot scripts. There is no resident helper or security-policy change.
